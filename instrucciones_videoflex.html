Paso 0

Preparar la carpeta del proyecto

Descomprimí el zip. Luego agregá manualmente los dos archivos marcados en verde — no están incluidos en el zip.

videoflex-build-v3/
  ├── videoflex_v3-1.py   ← el script Python de la app ✦ AGREGAR
  ├── assets/                ← carpeta del ícono ✦ AGREGAR
  │    ├── icon.ico         ← Windows (multi-res: 16,32,48,256px)
  │    └── icon.png         ← Linux (256×256px mínimo)
  ├── windows/
  │    ├── build_windows.bat
  │    └── videoflex_installer.iss
  ├── arch/
  │    ├── PKGBUILD
  │    └── build_arch.sh
  ├── debian/
  │    └── build_debian.sh
  ├── rpm/
  │    ├── videoflex.spec
  │    └── build_rpm.sh
  └── shared/
       ├── videoflex.spec
       └── version_info.txt
ℹ️

¿No tenés icon.ico? Podés convertir cualquier imagen PNG a ICO en convertico.com. El ícono es opcional — si no existe, los scripts usan el ícono genérico del sistema sin errores.

Windows 10 / 11
Genera VideoFlex.exe + VideoFlex_Setup_1.5.0.exe
.exe installer
1
Instalar Python 3.10 o superior

Descargalo desde python.org. Durante la instalación, marcá la opción "Add Python to PATH" — es imprescindible.

⚠️

Si no marcás "Add Python to PATH", el script no va a encontrar Python y fallará en el primer paso.

2
Instalar Inno Setup 6 (para el instalador .exe)

Descargalo desde jrsoftware.org/isinfo.php. Es opcional — sin él igual obtenés VideoFlex.exe portable, pero no el instalador con menú de inicio.

3
Ejecutar el script de build

Doble click en windows\build_windows.bat o desde CMD:

CMD / PowerShell
cd videoflex-build-v3\windows
build_windows.bat

El script hace todo automáticamente:

  • Verifica Python y su versión
  • Crea un entorno virtual aislado
  • Instala flet, pyinstaller, yt-dlp y dependencias
  • Detecta y activa el ícono automáticamente
  • Compila con PyInstaller (tarda 3–8 minutos)
  • Si Inno Setup está instalado, genera el instalador
  • Limpia los archivos temporales
4
Resultado en la carpeta windows\dist\
Archivos generados
dist\VideoFlex.exe                # Portable — copiar y ejecutar
dist\VideoFlex_Setup_1.5.0.exe   # Instalador completo (si Inno Setup está)
5
Instalar / desinstalar

Instalador: Doble click en VideoFlex_Setup_1.5.0.exe — crea acceso directo en el Menú Inicio, escritorio opcional y desinstalador en Panel de control.

Portable: Copiá VideoFlex.exe a cualquier carpeta y ejecutalo directamente.

Desinstalar: Panel de control → Programas → VideoFlex → Desinstalar.

Arch Linux / CachyOS / Manjaro
Genera videoflex-1.5.0-1-x86_64.pkg.tar.zst
.pkg.tar.zst
1
Instalar dependencias de build
Terminal
sudo pacman -S --needed base-devel python python-pip
2
Ejecutar el script de build
Terminal
cd videoflex-build-v3/arch/
chmod +x build_arch.sh
./build_arch.sh
⚠️

No uses sudo para ejecutar este script. makepkg no puede correr como root.

3
Instalar el paquete generado
Terminal
sudo pacman -U videoflex-1.5.0-1-x86_64.pkg.tar.zst
4
Ejecutar / Desinstalar
Terminal
videoflex            # lanzar desde cualquier terminal
sudo pacman -R videoflex  # desinstalar

Fedora / RHEL / Rocky / AlmaLinux / openSUSE
Genera videoflex-1.5.0-1.fc*.x86_64.rpm — detección automática de distro
.rpm
1
Instalar dependencias de build
Fedora / RHEL / Rocky / AlmaLinux
sudo dnf install python3 python3-pip rpm-build rpmdevtools

Ejecutar el script de build
Terminal

El script detecta automáticamente si usás dnf o zypper y ajusta los comandos.

3
Instalar el paquete .rpm
Fedora / RHEL

Ejecutar / Desinstalar
Terminal

sudo zypper remove videoflex   # openSUSE

Troubleshooting

Errores frecuentes y soluciones

Plataforma Error Solución
Windows 'python' no se reconoce como comando Reinstalar Python marcando "Add Python to PATH"
Windows Inno Setup no encontrado Normal — igual se genera VideoFlex.exe portable. Instalar Inno Setup para obtener el .exe instalador
Windows UPX is not available Warning inofensivo — el .exe se genera igual, solo sin compresión UPX
Arch makepkg must not be run as root Ejecutar ./build_arch.sh como usuario normal, sin sudo
Arch Cannot find the fakeroot binary sudo pacman -S fakeroot
Debian Depends: libgtk-3-0 but not installable sudo apt update && sudo apt install libgtk-3-0
Debian App no aparece en el menú sudo update-desktop-database
RPM rpmdev-setuptree: command not found sudo dnf install rpmdevtools
RPM error: Failed build dependencies El spec lista las dependencias faltantes — instalarlas con dnf install o zypper install
Todos ModuleNotFoundError: flet Borrar la carpeta venv_build_* dentro de la carpeta del build y volver a ejecutar el script
Todos El ejecutable no arranca (Linux) Verificar que GTK3 está instalado: apt install libgtk-3-0 / pacman -S gtk3
Personalización

Cambiar la versión del paquete

Editá la variable de versión en cada archivo antes de hacer el build:

# Arch
arch/PKGBUILD                 pkgver=1.5.0
 
# Debian
debian/build_debian.sh       APP_VERSION="1.5.0"
 
# RPM
rpm/build_rpm.sh             APP_VERSION="1.5.0"
rpm/videoflex.spec           Version: 1.5.0
 
# Windows
windows/build_windows.bat    set "AppVersion=1.5.0" (en el .bat y el .iss)
shared/version_info.txt     filevers=(1, 5, 0, 0)
